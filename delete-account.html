오늘의 값어치 계정 및 데이터 삭제 안내

앱 이름: 오늘의 값어치 · 개발자: ryanauto (TSD International)

오늘의 값어치는 별도의 회원 계정을 만들지 않습니다. 사용자가 "순위에 참여"를 켜면 기기마다 무작위 익명 식별자가 하나 만들어지고, 닉네임·시/도·날짜별 적립 금액·공개한 하루(사진, 한 줄)만 서버에 저장됩니다. 따라서 "계정 삭제"는 아래처럼 이 익명 식별자와 연결된 서버 기록을 지우는 것을 뜻합니다.

1. 앱 안에서 일부 데이터만 삭제하기

  • 공개한 하루는 그날 화면에서 "공개 취소"를 누르면 사진·한 줄·금액이 서버에서 즉시 삭제됩니다.
  • 기기 안의 기록(영수증, 사진, 목표, 담은 것)은 해당 화면에서 삭제하거나 앱을 삭제하면 모두 지워집니다.

2. 서버 기록 전체 삭제 (계정 삭제에 해당)

  1. 앱의 나 → 설정 → 순위에 참여를 끕니다. 이때 익명 식별자에 연결된 닉네임, 시/도, 날짜별 적립 금액, 공개한 하루(사진과 한 줄)가 서버에서 삭제됩니다.
  2. 앱을 삭제하면 기기 안의 모든 기록과 익명 식별자도 사라집니다. 재설치하면 새 식별자가 만들어지며 이전 기록과 연결되지 않습니다.

3. 삭제되는 데이터와 보관 기간

  • 삭제 대상: 익명 식별자, 닉네임, 시/도, 날짜별 적립 금액과 하루의 결, 공개한 하루의 사진·한 줄, 좋아요·신고 기록.
  • 위 절차가 끝나면 서버에 남는 데이터가 없으며 별도의 보관 기간이 없습니다. 삭제된 사진은 저장소에서도 함께 제거됩니다.
  • 광고(Google AdMob)와 결제(Google Play)에서 Google이 처리하는 정보는 Google의 정책을 따릅니다: https://policies.google.com/privacy

4. 도움이 필요하면

앱을 이미 삭제했거나 직접 처리가 어렵다면 tsdint@naver.com으로 앱에서 쓰던 닉네임과 대결 코드(있다면)를 함께 보내 주세요. 확인 후 서버 기록을 삭제하고 안내해 드립니다.
