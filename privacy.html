오늘의 값어치 개인정보처리방침

시행일: 2026년 11월 1일

오늘의 값어치(이하 "앱")는 사용자의 개인정보를 소중히 다룹니다. 본 방침은 앱이 어떤 정보를 다루고 어떻게 보호하는지 설명합니다.

1. 기기 안에만 저장되는 정보

앱의 기본 기능은 서버 없이 기기 안에서만 동작합니다. 아래 정보는 사용자의 기기 내부 저장소에만 저장되며, 사용자가 2항의 "순위 참여"를 켜지 않는 한 개발자를 포함한 외부로 전송되지 않습니다. 앱을 삭제하면 함께 삭제됩니다.

  • 사용자가 입력한 이름(닉네임), 생년월일, 목표 수명, 시/도
  • 오늘에 담은 것·목표·달성 기록, 날짜별 적립 금액과 누적 잔고, 영수증 보관 기록
  • 오늘의 한 컷(사진)과 한 줄: 사용자가 직접 찍거나 고른 사진만 앱 전용 폴더에 저장되며, 앱이 사진 보관함을 자동으로 읽지 않습니다.
  • 친구가 보낸 대결 코드

2. 순위 참여 시 서버에 저장되는 정보 (선택)

사용자가 앱 안에서 "순위에 참여"를 직접 켠 경우에만, 다음 정보가 개발자가 운영하는 서버(Supabase, 서울 리전)에 저장됩니다. 회원가입은 없으며, 기기마다 무작위 익명 식별자가 하나 만들어집니다.

  • 익명 계정 식별자(무작위 ID, 이메일·전화번호 없음)
  • 사용자가 입력한 닉네임과 선택한 시/도
  • 날짜별 순 적립 금액과 하루의 결(빛나는/따뜻한/잔잔한/흘러간 하루)
  • 사용자가 "오늘 하루 공개하기"를 누른 날에 한해: 그날의 한 컷 사진, 한 줄, 적립 금액

이 정보는 다른 참여자에게 닉네임·지역·금액 형태로 보입니다. 공개한 하루는 언제든 "공개 취소"로 삭제할 수 있고, 순위 참여를 끄면 서버의 내 기록이 삭제되며 새 정보가 올라가지 않습니다. 사용 기록, 걸음 수, 목표, 담은 것의 내용은 서버에 올라가지 않습니다. 부적절한 게시물은 신고할 수 있으며, 신고가 3건 이상 쌓이면 자동으로 숨겨집니다.

3. 선택적으로 읽는 기기 데이터

사용자가 앱의 "폰 데이터 연결" 화면에서 직접 켠 경우에만 다음 데이터를 읽습니다. 모두 기기 안에서만 계산되어 하루 값어치에 반영되며, 외부로 전송되거나 개발자에게 전달되지 않습니다.

  • 사용 기록 (Android "사용 정보 접근" 권한): 화면이 켜진 시간, 잠금 해제 횟수, 앱별 사용 시간, 화면이 꺼진 시간으로 추정한 기상·취침 시각. 사용자가 '시간 도둑'으로 지정한 앱의 사용 시간을 잃은 값어치로 환산하는 데 씁니다.
  • 걸음 수 (신체 활동 권한): 기기 걸음 센서의 누적값으로 오늘 걸음 수를 계산합니다.

두 권한은 휴대폰 설정 또는 앱의 '폰 데이터 연결' 화면에서 언제든 끌 수 있으며, 끄면 해당 항목은 계산에서 빠집니다.

4. 친구 대결 코드

'대결 코드'에는 사용자가 입력한 이름, 최근 7일 금액, 연속 일수, 그리고 순위 참여 중이라면 익명 식별자가 담깁니다. 코드는 사용자가 직접 복사하거나 공유할 때만 기기를 떠나며, 앱이 자동으로 전송하지 않습니다. 친구가 보낸 코드는 기기 안에만 저장되고 언제든 삭제할 수 있습니다.

5. 사진 저장 및 공유

'갤러리에 저장' 기능을 사용하면 한 컷 사진과 영수증 이미지가 기기 갤러리에 저장됩니다. '공유' 기능은 사용자가 선택한 앱으로만 이미지를 전달하며, 앱이 별도로 정보를 보관하거나 전송하지 않습니다.

6. 광고 (Google AdMob)

앱은 무료로 제공되며 화면 아래에 Google AdMob 배너 광고를 표시합니다. 광고를 보여주기 위해 Google은 다음 정보를 수집·이용할 수 있습니다.

  • 광고 ID(Advertising ID), 기기 정보(기종, OS 버전, 언어), 대략적인 위치(IP 주소 기반), 앱 사용 여부
  • Google의 정보 처리 방식: https://policies.google.com/technologies/ads
  • 광고 ID는 기기 설정 → Google → 광고에서 재설정하거나 맞춤 광고를 끌 수 있습니다.

"광고 없애기"를 구매하면 광고가 표시되지 않고 광고 SDK도 더 이상 광고를 요청하지 않습니다.

7. 인앱 결제 (광고 없애기)

"광고 없애기"는 Google Play 인앱 결제로 한 번만 구매하는 상품입니다. 결제는 Google Play가 처리하며, 앱과 개발자는 사용자의 결제 수단 정보(카드 번호 등)를 받지 않습니다. 앱은 구매 완료 여부만 기기에 저장하며, 같은 Google 계정으로 다른 기기나 재설치 후에도 복원됩니다. 결제 관련 정보 처리: https://policies.google.com/privacy

8. 알림

사용자가 허용한 경우, 앱은 아침·낮·저녁에 기기 안에서 예약한 알림을 보냅니다. 알림 내용은 기기 안에서 만들어지며 외부 서버를 거치지 않습니다. 알림은 앱 설정 또는 휴대폰 설정에서 언제든 끌 수 있습니다.

9. 제3자 제공

앱은 위 광고·결제 목적으로 Google에 전달되는 정보와 사용자가 직접 켠 순위 참여 정보 외에는 사용자의 정보를 제3자에게 제공하거나 판매하지 않습니다. 별도의 분석 도구는 사용하지 않습니다.

10. 정보의 삭제

  • 공개한 하루는 앱에서 "공개 취소"로, 서버의 순위 기록은 설정에서 "순위 참여"를 끄면 삭제됩니다.
  • 앱을 삭제하면 기기 안의 모든 기록이 삭제됩니다.
  • 자세한 절차는 계정·데이터 삭제 안내를 참고하세요.

11. 아동의 개인정보

앱은 만 14세 미만 아동을 대상으로 하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다.

12. 방침의 변경

본 방침이 바뀌면 앱 업데이트 안내 또는 이 페이지를 통해 알립니다.
